### Hi, I'm Pablo 👋

I write safety-critical C for GNSS ground segment systems. Before software, I did a PhD in RF/microwave engineering for space.
I like building things from the bottom up: compilers, binary formats,
memory allocators.

**What I'm working on**
- **[zinc](https://github.com/ansuzgs/zinc)**: a compiler for a subset of C,
  written from scratch in C99. Lexer, Pratt parser, name resolution and type
  checking done; bytecode VM and x86-64 backend in progress. Companion code
  for my book *Compiladores desde cero*.
- **[bitstream.h](https://github.com/ansuzgs/bitstream.h)**: header-only C99
  library for reading and writing arbitrary-width bit streams, tested under
  ASan/UBSan at -O0 and -O2.
